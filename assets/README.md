# Assets Directory

This directory is for app assets like icons and splash screens.

## Required Assets for Production:

- **icon.png** - App icon (1024x1024px)
- **splash.png** - Splash screen image
- **adaptive-icon.png** - Android adaptive icon (1024x1024px)
- **favicon.png** - Web favicon (48x48px)

You can generate these using tools like:
- https://www.appicon.co/
- https://icon.kitchen/
- Figma/Sketch/Adobe XD

For now, the app will work without these assets during development.
